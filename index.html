Welcome to the GradsMonanApp Website

This is an application that mimics the GrADS software (OpenGrADS), developed by COLA (cola.gmu.edu). It extends the functions of GrADS by adding new functions and commands. Developed in Python, it can open the output of the MONAN/MPAS models and also the output of the MOM6, ROMS and WRF models. MONAN/MPAS output can be opened directly on the Voronoi grid or even on a regular grid. (under a Creative Commons Attribution 3.0 Licence), which means that you are free to download and use it for anything you want.

This code is written entirely in python.
