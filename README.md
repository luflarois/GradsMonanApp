This is an application that mimics the GrADS software (OpenGrADS), developed by COLA ([cola.gmu.edu](https://cola.gmu.edu)). It extends the functions of GrADS by adding new functions and commands. Developed in Python, it can open the output of the MONAN/MPAS models and also the output of the MOM6, ROMS and WRF models. MONAN/MPAS output can be opened directly on the Voronoi grid or even on a regular grid.

Installation and operation instructions are available in the [User Manual](userManual.md). A [Quick Reference Guide](refcard.pdf) ([Markdown version](refcard.md)) is also available for fast consultation.

Please report any bugs you find so that they can be fixed, and new features are very welcome! 🄯
